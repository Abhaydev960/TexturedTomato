# TexturedTomato

A desktop application for extracting, processing, and working with textures from images.

## Overview

Texture Extractor is a tool designed to simplify texture-related workflows through a clean and straightforward interface.

It currently offers three modes:

### 1. Extract
Select a four-corner region of an image and flatten it into a texture using perspective correction.

### 2. Seamless
Blend the edges of an image using a circular blur effect. Adjust the blur radius with a slider to control the blending area.

### 3. Decals
Place a decal image onto an existing texture.

## Features

- Image importing and texture processing.
- Four-corner perspective selection.
- Adjustable selection points.
- Zooming and panning.
- Customizable output size.
- Adjustable edge-blending radius.
- Decal placement on textures.
- Undo support.
- Texture export.
